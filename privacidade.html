Política de Privacidade

Última atualização: 8 de novembro de 2026

Esta política descreve como a aplicação N8N Acesso, operada por Carlos Gabriel (Gabriel Dev MKT — gabrieldevmkt.com), acessa, usa e protege dados obtidos por meio das APIs do Google.

1. Sobre a aplicação

O N8N Acesso é uma aplicação de uso privado que conecta uma instância própria e auto-hospedada do n8n (n8n.gabrieldevmkt.com) às contas Google do próprio proprietário, para executar automações pessoais e de trabalho. A aplicação não é oferecida ao público.

2. Dados acessados

Com a autorização expressa do usuário, a aplicação pode acessar os seguintes dados do Google, somente na medida necessária para cada automação:

  • Informações básicas da conta (nome e endereço de e-mail);
  • Mensagens e marcadores do Gmail;
  • Arquivos do Google Drive, Planilhas Google e Documentos Google;
  • Agendas e eventos do Google Agenda.

3. Como os dados são usados

Os dados são usados exclusivamente para executar as automações configuradas pelo próprio usuário, como ler e enviar e-mails, criar e atualizar planilhas e documentos, organizar arquivos e gerenciar eventos de agenda.

Os dados não são vendidos, alugados, compartilhados com terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial genéricos.

4. Armazenamento e segurança

Os tokens de acesso OAuth ficam armazenados de forma criptografada no servidor privado onde a instância do n8n está hospedada. O acesso ao servidor é restrito ao proprietário e protegido por conexão HTTPS. Os dados do Google são processados apenas durante a execução das automações e não são mantidos além do necessário para elas.

5. Uso limitado dos dados do Google

O uso e a transferência, para qualquer outra aplicação, de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Após a revogação, a aplicação deixa de acessar qualquer dado da conta.
